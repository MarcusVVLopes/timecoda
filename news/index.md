# Changelog

## timecoda 0.6.1

- The README and the six articles are rewritten. Each article follows
  one worked analysis from data to result.
- [`print()`](https://rdrr.io/r/base/print.html) of an
  [`optimal_composition()`](https://marcusvvlopes.github.io/timecoda/reference/optimal_composition.md)
  search is organized into sections (search, region limits, zones,
  gain), with long lines wrapped to the console width.
- The website’s reference page for
  [`plot_ternary()`](https://marcusvvlopes.github.io/timecoda/reference/plot_ternary.md)
  no longer links to a missing external page.

## timecoda 0.6.0

`timecoda` 0.6.0 is the first public release.
